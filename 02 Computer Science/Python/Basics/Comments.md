# Comments

A **comment** is a piece of text in a Python program that is ignored by the Python interpreter.

Comments are used to **explain the code** and make it easier to understand.

---

## Single-Line Comment

A single-line comment starts with `#`.

```python
# This is a comment
print("Hello World")
```

The comment is ignored when the program runs.

---

## Multi-Line Comment

Python does not have a dedicated multi-line comment syntax.

Triple quotes (`'''` or `"""`) can be used for multi-line strings and are commonly used as documentation strings.

```python
"""
This is a multi-line
comment-like block.
"""

print("Hello World")
```

---

## Example

```python
# Store the user's name
name = "Nemis"

# Display the name
print(name)
```

**Output:**

```text
Nemis
```

---

## Program

```python
# Program to display student information

name = "Nemis"
age = 20
marks = 85.5

# Display student information
print("Name:", name)
print("Age:", age)
print("Marks:", marks)
```

**Output:**

```text
Name: Nemis
Age: 20
Marks: 85.5
```
