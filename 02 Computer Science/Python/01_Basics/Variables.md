# Variables

A **variable** is a container used to store data inside a program.

The data stored in a variable can be **text, numbers, characters, or boolean values**.

## Creating Variables

In Python, a variable is created by assigning a value to it using the `=` operator.

```python
name = "Nemis"
age = 20
percentage = 85.5
grade = 'A'
is_student = True
```
