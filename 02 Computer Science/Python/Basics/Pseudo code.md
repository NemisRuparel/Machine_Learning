# Pseudocode

**Pseudocode** is a simple way of writing the logic or steps of a program using plain English and programming-like statements.

It is **not actual Python code** and cannot be directly executed.

Pseudocode helps to plan the logic of a program before writing the actual code.

---

## Example

### Problem

Write a program to find the sum of two numbers.

### Pseudocode

```text
START

INPUT first number
INPUT second number

sum = first number + second number

DISPLAY sum

END
```

### Python Program

```python
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

sum = a + b

print("Sum =", sum)
```

**Input:**

```text
Enter first number: 10
Enter second number: 20
```

**Output:**

```text
Sum = 30
```

---

## Common Pseudocode Keywords

| Keyword | Purpose |
|---|---|
| `START` | Indicates the beginning of the algorithm |
| `END` | Indicates the end of the algorithm |
| `INPUT` | Takes input from the user |
| `DISPLAY` | Displays output |
| `IF` | Checks a condition |
| `ELSE` | Executes when the condition is false |
| `FOR` | Repeats a block for a fixed range |
| `WHILE` | Repeats while a condition is true |
