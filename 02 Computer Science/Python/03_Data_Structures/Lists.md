# Lists

A **list** is a collection used to store multiple values in a single variable.

Lists are **ordered, changeable (mutable), and allow duplicate values**.

A list is created using square brackets `[]`.

```python
fruits = ["Apple", "Banana", "Mango"]

print(fruits)
```

**Output:**

```text
['Apple', 'Banana', 'Mango']
```

A list can contain different types of data.

```python
data = ["Nemis", 20, 85.5, True]

print(data)
```

**Output:**

```text
['Nemis', 20, 85.5, True]
```

## Characteristics of Lists

- **Ordered** → Items maintain their position.
- **Mutable** → Items can be changed after creating the list.
- **Allows duplicates** → The same value can appear multiple times.
- **Heterogeneous** → A list can contain different data types.
- **Indexed** → Each item has an index starting from `0`.

## Example

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[0])
print(numbers[2])
```

**Output:**

```text
10
30
```
